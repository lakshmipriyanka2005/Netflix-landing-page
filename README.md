# Netflix Landing Page

A Netflix-inspired landing page created using HTML, CSS, and Bootstrap.

## 📌 Project Overview

This project is a front-end recreation of a Netflix-style landing page. 
It contains a navigation section, hero section, trending movies, reasons to join, FAQ accordion, and footer.

## 🚀 Features

- Netflix-style navigation bar
- Hero/banner section
- Email input and membership CTA
- Trending movies section
- Movie ranking cards
- Reasons to join section
- Frequently Asked Questions accordion
- Language dropdown
- Responsive layout
- Netflix-inspired dark theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
